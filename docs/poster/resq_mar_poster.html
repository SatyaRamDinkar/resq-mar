1. PROBLEM & MOTIVATION

  • Natural disasters are increasing globally; response time is critical for survival.
  • Current systems (e.g., ResQConnect) rely on cloud APIs like GPT-4o -- they fail offline.
  • Static vehicle routing cannot adapt to dynamic disaster conditions (e.g., blocked roads).
  • Fully automated AI dispatch lacks essential human oversight in life-or-death decisions.
  • High cost barriers prevent advanced deployment in developing nations.
ResQ-MAR removes ALL these barriers: 100% free, 100% local, 100% open-source.

4. WHY RESQ-MAR WINS

COST
$0 vs $$$$ (GPT-4o API costs). Any municipality can deploy.
RESILIENCE
Edge SLM works offline. Cloud fails; ResQ-MAR continues to operate.
INTELLIGENCE
Agentic RAG + AET routing + human oversight. AI augments, not replaces.
