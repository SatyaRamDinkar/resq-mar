# ResQ-MAR Poster Assets

This directory contains the single-file, zero-dependency academic poster for the ResQ-MAR final capstone presentation.

## Quick Reference
- **Poster File**: `docs/poster/resq_mar_poster.html`
- **Format**: Single HTML file with inline CSS (no internet connection required to view or print).
- **Dimensions**: A1 Portrait (594mm x 841mm).
- **Safety**: 100% ASCII-compliant text, ensuring no missing characters across operating systems.

## How to Customize
If you need to update the University Name, Author Names, or tweak the colors:
1. Open `resq_mar_poster.html` in VS Code or any text editor.
2. Locate the `<div class="header">` block at line ~85 to change the title, authors, and affiliation.
3. Locate the `<style>` block at line ~6 to adjust the primary colors (`#1a1a2e` Navy, `#e94560` Red).
4. Save and refresh your browser.

See `print_guide.md` for detailed instructions on exporting to PDF for the physical print shop.
