# Using the ResQ-MAR Documentation

This directory contains the end-user documentation for the ResQ-MAR system.

## Where to Find the Manuals
- Full Documentation: `docs/manual/USER_MANUAL.md`
- Quick Start: `docs/manual/QUICK_START.md`

## How to Read
These manuals are written in standard Markdown format. You can open them using:
- Visual Studio Code (Right-click -> Open Preview)
- Typora or Obsidian
- GitHub's native web viewer

## How to Print or Convert
To include this manual in your bound capstone report or university submission:
- Use the VS Code extension **Markdown PDF** to export directly to PDF format.
- Alternatively, use `pandoc docs/manual/USER_MANUAL.md -o user_manual.pdf`.

## Inclusion in Submission
- Burn these Markdown files (along with any generated PDFs) directly to your submission CD/USB.
- Ensure you reference the User Manual in your report appendix.

## Target Audiences
Please consult the following chapters based on your role:
- **Dispatchers:** Read Chapters 1, 4, 5, and 7.
- **System Administrators:** Read Chapters 1, 2, 3, 6, and 7.
- **Developers:** Read Chapters 1, 2, 3, 6, and 8.
