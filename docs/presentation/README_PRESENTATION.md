# ResQ-MAR Final Review Presentation

This directory contains the automated Reveal.js slide deck for the final capstone presentation.

## 1. How to Present
- Open `docs/presentation/final_review.html` in Google Chrome or Microsoft Edge.
- Press `F11` to enter full-screen mode.
- **Critical Feature**: Press `s` on your keyboard to open the **Speaker Notes** window. Drag this window to your laptop screen while projecting the main slides on the wall.
- Navigate using the arrow keys, spacebar, or a clicker.
- Press `o` to zoom out into an overview grid of all slides.

## 2. How to Export to PDF
If your professors require a hard copy or PDF of the slides:
1. Open the file in Chrome but append `?print-pdf` to the URL. (e.g. `file:///C:/.../final_review.html?print-pdf`)
2. Wait a second for the layout to change.
3. Press `Ctrl + P`.
4. Set Destination to "Save as PDF".
5. **Layout**: Landscape
6. **Margins**: None
7. **Background graphics**: Enabled (Checked)
8. Click Save.

## 3. How to Import into PowerPoint (Optional)
Reveal.js provides a smoother, more cinematic presentation style than PowerPoint. However, if PPT is strictly required:
- *Method 1*: Take a full-screen screenshot of each HTML slide and paste them into a blank PPT.
- *Method 2*: Export to PDF (see above), then use Adobe Acrobat to "Export To -> Microsoft PowerPoint".
- *Method 3*: Manually copy the text content from the HTML into your own PPT template.

## 4. Presentation Tips
- Practice with a timer! Your target is **12-15 minutes**.
- Use the provided `speaker_script.md` to memorize your transitions.
- Do not read directly off the slides. Let the audience read the text while you narrate the story using the speaker notes.
- Have the `scripts/run_full_demo.py` terminal ready in the background in case the panel asks for a live demonstration during Q&A.
