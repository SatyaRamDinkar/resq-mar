How to Run the Main Code (in order, before the review)



bash
# 1. Get the project
git clone https://github.com/SatyaRamDinkar/resq-mar.git
cd resq-mar
pip install -r requirements.txt

# 2. Start the AI brain (new terminal)
ollama serve
ollama pull llama3.1

# 3. Start the map router (only if Docker container isn't already running)
docker run -d -p 5000:5000 --name osrm-router -v "${PWD}/data/osrm:/data" osrm/osrm-backend osrm-routed --algorithm mld /data/india-latest.osrm

# 4. Start the dashboard (new terminal)
python -m streamlit run frontend/streamlit_app_enhanced.py
Then open http://localhost:8501. Verify the router works with: curl "http://localhost:5000/route/v1/driving/77.2090,28.6139;75.7873,26.9124?overview=false" — if it returns distance/duration, you're demo-ready.
⚠️ Do this tonight, not tomorrow morning — if the Docker container isn't running or the .osrm file wasn't processed on this machine, you need time to fix it.
